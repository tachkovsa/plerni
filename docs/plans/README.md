# Plans

Implementation plans live here. The schedule model once planned as a capacity annex was withdrawn (issue #15); the contributor entry point is [`../ROADMAP.md`](../ROADMAP.md). A plan is merged only after its review chain is complete (see `docs/ai/model-routing.md`); the revision-bound receipt for a plan lives in its landing PR's body, and the review chain is summarized in a companion `*-review-receipt.md` file.

Current: `2026-10-13-p0-implementation-plan.md` (+ its detailed execution breakdown and review chain).
