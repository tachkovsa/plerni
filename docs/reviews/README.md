# Review evidence

The design of Plerni was adversarially reviewed across multiple model families (Kimi K3, GPT 6.1 "Sol", GLM 5.3, Claude Opus 5.5) plus a historical counter-evidence pass against the predecessor repository.

The raw transcripts cite predecessor-internal details (private tracker IDs, internal paths, client-adjacent references) and are therefore **retained privately** by the maintainer — see the repository's public-data policy in `AGENTS.md`. `SHA256SUMS.txt` in this directory is the integrity manifest: each transcript's hash, so the private archive can be verified against what the public design claims.

If you need a transcript for audit, ask the maintainer (see GOVERNANCE.md).
